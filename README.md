# US H1B Visa Data Analysis Project

This project focuses on analyzing H1B visa data to uncover trends, patterns, and insights using **Python for data cleaning** and **Power BI for visualization**.
![Dash Board View](https://github.com/Akash91700/H1B-Visa-Case-Study/blob/main/Screenshot%201%20.png)
---

## 📊 Tools & Technologies Used

* 🐍 Python (Pandas, NumPy)
* 📊 Power BI (Dashboard & Visualization)
* 📁 Dataset (External Source)

---

## 📂 Dataset Source

The dataset is large and is sourced from the official website:

🔗 https://www.dol.gov/agencies/eta/foreign-labor/performance

---

## 🎯 Project Objectives

* Analyze H1B visa application trends
* Identify top job roles and industries
* Study salary distribution
* Understand approval vs denial patterns

---

## 📈 Key Insights

* ✔ Majority of H1B applications are from IT-related roles
* ✔ Certain states dominate visa approvals
* ✔ Higher wages often correlate with higher approval rates
* ✔ Demand for skilled professionals is increasing yearly
